## Accepted behavior

Permission is non-persisted and exact-window/session/target/revision bound. START
captures output config and source identity, owns `ActuatorOutput`, and replies only
after a complete first output bank. Updates are operation/request/revision scoped.
STOP/E-STOP use a priority path and confirmed full-bank Release. Prepared loss is
passive; owner close/deadline releases without renderer cooperation; target
replacement cannot redirect old output/Release and retains uncertainty.

Tone/configuration use the same permission/context. Mapping and parameter reads are
target scoped; writes reuse the owned Parameter worker and are cancelled by OFF or
owner loss. Preflight opens Motor Test rather than issuing a global STOP.

SD capture owns an independent `Capture` claim and exact test/path. It can coexist
with actuation. Exact STOP or owner close confirms `logger off`; changed external
file identity sends zero stop command and retains reconciliation. Native/lifecycle
cleanup waits for Motor Release, capture finalization and log cleanup before tool
observers/dedicated I/O; borrowed primary transport/cache remains open.

Dedicated logs now use one existing generation-bound `LogService`; borrowed Motor
reuses the primary worker instead of opening another protocol worker/transport.
List/download/delete/erase and exact cancel are operation scoped. Download picker
precedes admission, identity is re-listed, local writes use cancellable blocking I/O,
exclusive temporary siblings, file/directory sync and final generation checks.
Cancellation sends END and waits for quiet. Delete/erase recheck idle/disarmed/logger,
id/time/size/path immediately before writes and verify read-back. Uncertain deletion
sets a native refresh barrier.

## Manual and residual hardware checks

1. Run dedicated and borrowed-main sessions. ON is passive; 3 s START, updates,
   STOP and native close affect only that operation. Borrowed main telemetry/cache
   remains usable.
2. Start capture, run motors, STOP motors, then stop capture. Verify independent
   lifetime and exact file. Change logger/file externally: old capture must not
   stop it and reconciliation must remain visible.
3. Cancel list/download and the save picker; verify no cross-operation effect or
   partial file. Exercise two-confirm delete/erase and read-back barriers.
4. On hardware, record PX4/ESC versions, physical mapping, FC timeout, every
   selected AM32 tone, Release-to-configured-disarmed-output, rotor stop timing,
   external QGC/RC interaction and emergency behavior. These physical facts are
   not inferred from transport receipts.
