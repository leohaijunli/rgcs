## 1. 证据与阅读约定

本次参考了视频元数据、英文自动字幕、抽样视频画面及官方手册。自动字幕可能误识别名称、单位和数值，因此以下内容优先使用明确的控件名称、章节时间点，以及能够交叉核对的行为。只有来源明确给出时才记录软件版本。

**数值参数均为视频中的机型和场地示例。** 它们有助于复现教程，但不是通用航测默认值。相机重叠率、磁测测线间距、爬升/下降限值及返航电量阈值，分别对应不同的作业要求。

视频横跨 2016–2024 年；2026-10-25 查阅的当前手册包含后续版本行为。旧视频演示的限制，不能直接视为当前 UgCS 仍然存在的限制。

## 2. 通用操作模型

这些视频反复出现的工作流是：

1. 新建并命名 Mission，添加飞行器。
2. 新建 Route，关联正确的飞行器配置（Vehicle profile）。
3. 绘制测区边界或导入几何数据。
4. 选择 Survey 工具，设置几何、高度、速度和载荷参数。
5. 添加、排序起点、测区、转场、校准及结束航段。
6. 计算航线，同时检查三维路径和高程剖面。
7. 处理航线／机型约束，检查预计时长与航点数量。
8. 上传到目标飞行器，使用对应平台的控制方式执行。
9. 监视位置、高度、链路和电量；需要时中断、换电并续飞。

需要区分的概念：

- **测区边界**定义覆盖范围，不等于完整飞行路径。
- **航段**在展开成具体航点之前，保留用途及参数。
- **首航点、实际起飞位置、Home、返程航点、降落点**相互有关，但不是同一个概念。
- **Area Scan**直接输入高度和线间距；**Photogrammetry**根据相机、GSD 和重叠率计算几何。
- 上传成功与完成合格测量是不同结果。这些视频没有证明完整的航线质量或磁测数据验收体系。

## 3. 逐视频操作步骤

### V01 — 基础航线、插入航段与动作

**起始环境：** UgCS 2.11，四旋翼模拟器。

| 时间 | 操作 | 应看到的结果 |
| --- | --- | --- |
| 00:22–00:41 | Menu → Create new mission；点击任务标题，重命名并确认。 | 当前 Mission 有明确名称。 |
| 00:41–01:47 | Add vehicle；从零新建 Route；命名并选择匹配的机型 profile；查看 Home、高度、轨迹和 failsafe 参数。 | 出现 Route 卡片与航段工具。 |
| 01:47–02:24 | 在实际起飞位置附近用 Shift-click 或双击放置首航点；拖动地面控制点改变位置，拖动高度控制点或输入数值改变高度。 | 航点坐标与高度随编辑更新。 |
| 02:24–02:55 | 选择 Stop and turn；示例速度设为 6 m/s；继续添加去程和返程航点。 | 后续新增点继承当前编辑参数。 |
| 02:55–04:06 | 删除目标附近的检查航点；选中其后一个航段，启用“在此前插入”，选择 Circle 并放置；调整圆心、半径，示例半径 50 m。 | 圆形航段插入正确位置，而不是追加到任务末尾。 |
| 04:06–04:49 | 在圆形前设置相机 Start recording，之后设置 Stop recording；再添加 5 s Wait，并将其移动到开始录像之前。 | 航段动作有明确执行顺序。 |
| 04:49–05:31 | 选择全部航段统一修改高度；打开 Show elevation。 | 批量编辑作用于所选航段；剖面显示 AMSL／AGL 范围、距离、时长及点数。 |
| 05:31–06:10 | Upload 并确认；在模拟器中执行 Arm、Auto mode。 | 上传反馈完成后开始执行航线。 |

**基线要点：** 自动生成的测区航线应能与手工航段、有序动作共同组成任务；插入位置属于操作语义的一部分。

## 4. 参数语义基线

| 参数／控件 | 含义与可观察影响 | 来源 |
| --- | --- | --- |
| Flight height + altitude mode | 高度数值必须带参考：AMSL、垂直 AGL、Smart AGL，或受支持的测距仪模式。 | V02、V03、D02 |
| Side distance／line spacing | Area Scan 中相邻测线之间的直接米制距离。 | V02、D01 |
| GSD + camera profile | 由相机几何和要求的影像分辨率确定名义飞行高度。 | V04、V05 |
| Forward／side overlap | 决定沿线拍摄间距与跨线间距，影响时长和照片数。 | V04、V05 |
| Direction angle | 测线方向；与平移／旋转完整航段是不同操作。 | V03、V05、D01 |
| First waypoint／entry | 影响入口角点选择，同时属于接近路径。 | V02–V05 |
| Turn type | 平台相关的停转／连续转弯行为；显示曲线不等于飞控执行契约。 | V01–V06、D08 |
| Overshoot／overshoot speed | 测线端点的延伸长度及对应区段的独立速度。 | V05、D01 |
| AGL tolerance | 控制附加地形航点及点数，不等于实际飞行高度精度保证。 | V05、D01 |
| Trajectory smoothing | 当前 Area Scan 提供 Max slope 和 Minimal gap。 | D01 |
| Action execution | Every point、At start、Forward passes；D01 还提供 No action at the last point。 | V05、D01 |
| Double grid | 增加相差 90° 的第二套网格；相机姿态仍可独立设置。 | V05、D01 |
| Additional capture waypoints | 需要时在每个拍照位置增加明确航点。 | V05 |
| Allow partial calculation | 当前 Area Scan 可在高度、缺失地形、围栏或 NFZ 导致部分区域受限时计算部分输出；应区分部分输出与完整覆盖。 | D01 |

D02 将 Smart AGL 描述为保持与**飞行线方向上最近表面**的距离，而不是普通 AGL 的垂直离地距离。该页面同时说明许可证和机型限制。测距仪闭环跟随与基于 DEM 生成航点，是不同的执行模式。

## 5. 由手册补充的操作流程

### 5.1 地图影像

进入 Map options → Map layers → Map：

1. **地理配准影像：** Add → 命名 → Geoserver → Create → Upload 地理配准 TIFF。
2. **XYZ 服务：** Add → 命名 → External → 填写 Remote Source → Create；调整 Base／Overlay 顺序。
3. **WMS：** Add → 命名 → External WMS → 填写服务 URL → 选择图层 → Create；调整 Base／Overlay 顺序。

预期结果：影像可见且空间位置正确。影像能够显示，不代表规划所需的高程数据已经可用。

### 5.2 高程数据

进入 Map options → Map layers → Elevation：

1. 添加并命名高程源。
2. 上传地理配准高程栅格，或配置外部高程源 URL。
3. 启用数据源，调整列表优先级，使用 Focus 查看覆盖区域。
4. 明确 DTM／DSM 角色，检查不同数据源交界位置。
5. 重新计算航线，检查高程剖面。

D05 说明内置 SRTM 的水平基准为 EPSG:4326，垂直基准为 EGM96。UgCS 导入时**不会转换不同垂直基准的高程**，混用基准可能在交界处形成台阶。手册还说明小于 1 m/pixel 的输入会降采样至 1 m/pixel。DTM 用于规划，DSM 用于地物净空评估。

### 5.3 PX4 连接与兼容性

本节依据手册，不是对缺失视频的还原。

1. 接入 UgCS 前，先通过 PX4／QGroundControl 流程完成机体配置、校准和验证。
2. 核对飞行器唯一身份及目标连接端点。
3. 将配对遥测电台或飞控 USB 接到运行 VSM 的计算机，确认操作系统识别串口。
4. 等待飞行器出现，修改名称并分配匹配的 profile。
5. 执行前核对支持的任务动作及实际飞行器限值。

**保留的版本差异：** D07 将系统 ID 参数写为 `SYSID_THISMAV`，而本地 PX4 v1.17 在 `src/modules/mavlink/mavlink_params.c` 中定义的是 `MAV_SYS_ID`。PX4 操作说明应以目标固件核实结果为准。D08 的轨迹／航向限制也不能视为已对所有后续 PX4 版本完成实测。

### 6.1 建议的对照场景

每个场景记录机型／profile／版本、输入几何、参数、生成统计、高程剖面和导出／执行结果。以下是**后续功能对照场景**，并非本次文档审查已经执行的测试。

1. 绘制不规则多边形，修改顶点、平移／旋转航段、改变测线方向，再使用导入边界重复操作。
2. 将起飞位置移到另一角落，核对入口选择及全部去程／返程航段。
3. 在山脊地形上改变 AGL tolerance，比较航点数量与最小净空。
4. 分别设置测量速度和 overshoot 速度，核对执行端收到的速度语义。
5. 比较 Every point、At start、Forward passes 的动作执行范围。
6. 复制单网格，启用双网格并修改相机姿态。
7. 更换相机，核对 GSD、间距、触发间隔和照片数。
8. 改变 DEM 优先级／基准，检查源数据交界和重新生成的剖面。
9. 触发航线限制或缺失地形区域，区分完整计算、部分计算与计算失败。
10. 在测线中途退出、换电，分别用直接接入和经过首航点的方式继续，检查实际覆盖。
11. 经其他应用导出／导入任务，核对高度，并明确需要重新配置的动作。
